# Project conventions

Phase 1 permits research and simulated trading only. Any future live capability requires the owner's explicit approval. Keep historical and synthetic data clearly labelled. Keep credentials, licensed datasets and private databases outside version control.

Use only the owner's explicitly configured Git author and committer identities. Do not invent identity values, add assistant attribution, automated contribution notices or co-author trailers. Respect applicable repository and platform disclosure requirements. Inspect both configured identities and actual commit metadata before a push. Pushing to GitHub requires explicit owner authorization.
